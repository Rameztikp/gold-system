# 02 — الشاشات

عامة: عربي RTL، ثيم داكن (افتراضي) وفاتح. على الجوال (≤ 820px): شريط سفلي، والنوافذ تظهر من أسفل الشاشة.

| الشاشة | المسار | المحتوى |
|---|---|---|
| الدخول | `#/login` | مفتاح مرور (صاحب المحل) أو اسم مستخدم + كلمة مرور (مدخل البيانات). إعداد أول مرة برمز الإعداد. |
| الإطار والقائمة | — | قائمة جانبية على الكمبيوتر، شريط سفلي على الجوال. زر الثيم. |
| اللوحة | `#/` | يوم / أسبوع / شهر. بطاقة «يحتاج انتباهك» (أيام لم تُقارن أو فيها خطأ). أربع بطاقات: المبيعات، المشتريات، المصروفات، الأجور. رسم يومي للمبيعات. |
| التقارير | `#/reports` | فترة من/إلى. ملخص وتفصيلي (كل السطور). طباعة و PDF (عبر الطباعة). |
| الأيام | `#/days` | قائمة الأيام بالحالة والمجاميع. زر «يوم جديد». |
| الإدخال | `#/day/:date` | رأس اليوم (التاريخ، السعر، الحالة، الصور). 4 خطوات: المبيعات، المشتريات، المصروفات، المقارنة بالدفتر. |
| يوم جديد | نافذة | اختيار التاريخ (الافتراضي: اليوم التالي لآخر يوم). |
| نافذة السطر | نافذة | إضافة، تعديل، إلغاء بسبب، إرجاع. اقتراحات البيان. سؤال التكرار. |
| صور الدفتر | داخل الإدخال | رفع (تصغير 1600px JPEG 0.82)، عرض. |
| البحث | `#/search` | بحث بالتطبيع العربي من بداية الكلمة. |
| الواتساب | زر في الإدخال | رسالة ملخص اليوم عبر wa.me. |
| سجل التعديلات | `#/admin/audit` | صاحب المحل فقط. |
| المستخدمون | `#/admin/users` | إضافة مدخل بيانات، إيقاف/تفعيل، مفاتيح المرور، رموز الاسترجاع. |
| الإعدادات | `#/admin/settings` | إعدادات الفرع: الاسم، العملة، رمز الدولة، التوقيت، بداية الأسبوع. |
